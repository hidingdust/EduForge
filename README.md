# EduForge
EduForge: A multi-agent interactive education platform. Upload doc/docx teaching materials, then a supervisor agent graph parses the content and generates classroom PPT, quizzes, and animated courseware, with SSE real-time progress and Redis checkpoint resume. 多智能体交互教育平台：上传教学文档，监督者智能体自动解析并生成课堂 PPT、随堂习题与演示动画，支持 SSE 实时进度与断点续跑。
